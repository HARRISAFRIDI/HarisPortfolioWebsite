# Haris Habib – AI Engineer Portfolio

Single-page portfolio built with React (UMD build from a CDN), HTML and CSS. No build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Sections

About, skills, experience timeline, projects, education and certifications, contact.
